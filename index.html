ℹ️ À propos de VespaTimer

Bienvenue sur VespaTimer*, un site internet qui facilite le travail du pot à mèche**, en faisant directement les moyennes et en triangulant le nid selon vos chronométrages.

Une fois vos relevés complétés, téléchargez le format souhaité (souvent PDF) puis transmettez-le à votre télémètre régional.

Pour refaire l'exercice, appuyez sur nouveau.

⚠️ N'oubliez pas de signaler vos observations (frelon, nid, etc.) sur : frelonasiatique.ch

🐝 Bonne chasse ! 🙂

Instructions : remplissez les infos en haut, chronométrez les frelons plusieurs fois, voyez où se trouve potentiellement le nid, exportez dans le format souhaité (PDF pour le télémètre / JSON pour réimporter les données plus tard, GPX/KML pour charger sur des cartes).

* Requiert une connexion Internet pour la date et l'heure ainsi que les services de localisation pour la précision de la carte. Veuillez signaler les bugs si vous en rencontrez.
